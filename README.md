## `> portfolio --preview`

The portfolio (`index.html`) + network dashboard (`network.html`) are built as a **single-page, fully animated experience** with:

- **Animated background** — moving grid, aurora blobs, floating particles, data stream lines
- **Scroll reveal** — sections fade and slide in on scroll via `IntersectionObserver`
- **Micro-robots** — animated CSS bots scattered across the UI (bobbing, blinking, arm-swinging)
- **Terminal log** — live server log panel with real-time streaming entries and color-coded statuses
- **Node graph** — interactive SVG network map; tap any node to open a modal with bot details
- **Contact form** — Formspree-powered with async AJAX, transmitting/success/error states
- **Zero dependencies** — pure HTML, CSS, and vanilla JS · no frameworks
